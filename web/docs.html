01 / OVERVIEW

What AMACS does

AMACS turns one broad prompt into a coordinated execution plan. The orchestrator owns decomposition and scheduling, specialists own focused sub-tasks, shared memory carries context between steps, and the synthesizer produces the final response.

Core ideaMake multi-agent work observable: tasks, dependencies, messages, adaptations, outputs, and quality signals are all returned as structured data.

02 / ARCHITECTURE

From brief to final plan

01InputUser brief enters the orchestrator.
02DecomposeWork becomes dependency-aware tasks.
03ExecuteSpecialists run in coordinated waves.
04ShareResults travel through shared memory.
05SynthesizeOne final plan is merged and returned.

The dashboard communication bus renders this as a graph. Animated particles represent message events; edge colors identify the phase of each event.

03 / CONFIGURATION

Provider setup

Offline mode is available without credentials and uses deterministic specialist responses for demonstrations and local UI development. Live AMACS orchestration requires both settings below.

GROQ_API_KEY=your-key
AMACS_ENABLE_LIVE=true
GROQ_MODEL=openai/gpt-oss-20b
PORT=8787
SettingPurposeDefault
GROQ_API_KEYEnables the Groq provider.unset
AMACS_ENABLE_LIVEAllows the coordinated live path.disabled
GROQ_MODELSelects the live model.openai/gpt-oss-20b
PORTHTTP server port.8787

04 / RECOVERY

Understanding fallback

Fallback is a controlled recovery path, not a second hidden provider. When live orchestration is disabled, the app deliberately uses offline specialists. When a live AMACS call raises an exception, the same offline path is used and the exception is recorded in the adaptation event.

LIVE PROVIDER DISABLEDCheck AMACS_ENABLE_LIVE and the API key. The run is labeled offline and explains that no live call was made.
PROVIDER FAILUREInspect the recorded exception, provider credentials, model name, rate limits, and network access. The response remains available through offline specialists.

07 / QUICK START

Run the demo

# AMACS is published on PyPI; no repository clone is needed.
python -m pip install amacs
python -m pip install groq
cp .env.example .env
python server.py

AMACS is installed directly from PyPI. Open http://localhost:8787 and submit an incident brief. Start offline first; add provider credentials only when you want to exercise live orchestration.
